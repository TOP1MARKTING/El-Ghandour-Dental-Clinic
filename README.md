# El-Ghandour Dental Clinic — عيادة الغندور للأسنان

نظام إدارة العيادة: حجز المرضى وترتيب الحضور، ملفات المرضى والعلاجات، المواعيد، الدفعات والخزنة، والخدمات والأسعار.

## التشغيل

```bash
npm install
npm run dev
```

الموقع بيشتغل على `http://localhost:8080`.

## البناء

```bash
npm run build
```
